## Materiali archiviati / Archived materials

- [Demo G.A.P. 2.0 in C++](GAP_2.0.cpp) — esempio autonomo di classificazione delle evidenze. Qui “G.A.P.” ha un significato diverso dal protocollo G.A.P.-001 del repository (**Active Paranoia Management**); il demo non è collegato al runtime Python.
- [Specifiche e strumenti HumOS V.18.3.1](HumOS_V18.3.1_Specifica_Completa_e_Tool_LINGHOS.docx) — proposta architetturale e LINGHOS originale in italiano, conservata come documento storico. Per il contratto e i limiti implementativi correnti, consulta la [specifica LINGHOS](../docs/SPEC.md).

- [G.A.P. 2.0 standalone C++ demo](GAP_2.0.cpp) — an evidence-classification example. Its use of “G.A.P.” is separate from this repository’s G.A.P.-001 protocol (**Active Paranoia Management**); the demo is not connected to the Python runtime.
- [HumOS V.18.3.1 specification and tools](HumOS_V18.3.1_Specifica_Completa_e_Tool_LINGHOS.docx) — the original Italian architecture and LINGHOS proposal, kept as a historical document. See the current [LINGHOS specification](../docs/SPEC.md) for the present contract and implementation boundaries.
